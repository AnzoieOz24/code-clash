# Code Clash

A two-player real-time reaction game built with Node.js, Express and WebSockets.

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

## Deploy
This project is ready for hosts that run a Node web service and support WebSockets (for example Render). Build command: `npm install`; start command: `npm start`.

## Game rules
Two players share a room code. Each round, a target appears for both players. The first player to click it earns one point. First to 10 points wins.
